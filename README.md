# Агент 0,5 — доставка ко дню рождения

2D-платформер-подарок про агента по поставкам пива и его белую Kia Rio.
Android-приложение, внутри которого HTML5-игра (`app/src/main/assets/index.html`).

**Имя именинника** впишите в начале скрипта в `index.html`:
`const HB_NAME='';` → например `const HB_NAME='Саша';`
Оно появится в финальном поздравлении и на растяжке в баре.

## Сборка в Code on the Go (из GitHub)

1. В Code on the Go на главном экране выберите **Clone Git repository**.
2. Вставьте адрес: `https://github.com/mishpip31-droid/Beer-Dealer.git`
   дождитесь клонирования и откройте проект.
3. Дождитесь синхронизации Gradle (в первый раз нужен интернет).
4. Запустите сборку **assembleDebug** (кнопка ▶ / Build).
5. APK появится в `app/build/outputs/apk/debug/app-debug.apk`; установите его.

Если IDE ругается на версию Android Gradle Plugin, поменяйте версию в
`build.gradle` (строка `id 'com.android.application' version '8.2.2'`) на ту,
что стоит в шаблонах Code on the Go, а в `gradle/wrapper/gradle-wrapper.properties`
укажите подходящую версию Gradle.

## Готовый APK с GitHub

При каждом пуше GitHub Actions собирает APK (workflow **Build APK**).
Скачать: вкладка **Actions** → последний запуск → артефакт `beer-hero-apk`.

## Проверить игру без сборки

Откройте `app/src/main/assets/index.html` в браузере на компьютере или телефоне.

## Меню

На старте — меню: «Играть с начала» или выбор уровня. Уровень открывается, как только
до него дошёл (прогресс сохраняется на телефоне). В паузе ⏸ есть кнопка «В меню».

## Управление

- Телефон: кнопки ◀ ▶ слева, ▲ (прыжок) справа, 🍾 (бросок бутылки, появляется с кружкой пива); ⏸ пауза, 🔊 звук.
- Клавиатура: ← → / A D; прыжок: ↑, W, пробел; бросок: X.

## Сюжет

Утро дня рождения. Звонит начальник: «Срочный заказ! Пять точек, всё развезти до 19:00!»

1. **Склад завода** — конвейеры, паровые клапаны, бочки. Собери 3 накладные 📄,
   у отгрузки ящики грузятся в багажник белой Kia Rio.
2. **Трасса** — едем на Kia Rio по трём полосам: ▲▼ — перестроиться, ⤴ — прыжок.
   Ямы, конусы и лужи можно объехать или перепрыгнуть, попутные машины — только объехать. Кофе ☕ — турбо.
   В конце — гаишник с жезлом: проскочи 3 поста, пока он отвернулся (◀ — тормоз).
3. **Магазин «У дома»** — мокрый пол, тележки, кактусы и живые продукты: 🍌 банан (бросает кожуру —
   поскользнёшься), 🥚 яйцо (падает с полки, когда проходишь под ним), 🥫 кетчуп (плюётся).
   Босс — **придирчивая заведующая**, кидается ценниками. Награда — подписанная накладная.
4. **Гипермаркет** — огромный зал: металлические стеллажи с паллетами, кассы, блестящая плитка.
   Живые продукты: 🍉 арбуз (после прыжка раскалывается на дольки), 🍦 мороженое (замораживает, бить
   только бутылкой), 🍿 попкорн (взрывается рядом залпом зёрен), 🥫 кетчуп.
   Босс — **агент конкурентов**: кидает свои бутылки и катит тележки «выкладки».
5. **Гаражи** — пока герой воевал за полки, Kia Rio увёз **эвакуатор**!
   Догоняем по гаражам, босс-эвакуатор таранит и роняет конусы — прыгай ему на крышу.
6. **Сюрприз дома** — Kia Rio подъезжает к дому, в квартире темно… загорается свет — «СЮРПРИЗ!»,
   выбегают родственники и собака, поздравления, а потом салют.

- Ящики с «?»: золотые крышки, **кружки с пивом** (можно кидать бутылки, выдержать удар,
  разбивать кирпичи; вторая кружка делает героя больше — это ещё один запасной удар), кренделя (+1 жизнь). 5 жизней, чекпоинты, последний — перед боссом.
- В углу — шкала «📈 План», сколько всего заказа уже развезено.

Отладка в браузере: `index.html?lvl=3&boss=1` — старт с нужного уровня/босса, `?lvl=6` — сразу финал.
